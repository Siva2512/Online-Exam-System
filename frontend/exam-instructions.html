General Rules & Honor Code

  • The countdown timer starts as soon as you click Start exam.
  • Each question presents four options with exactly one correct answer.
  • You may navigate between questions freely using the question palette.
  • Select an answer to save it immediately. You can modify your choices at any time prior to submission.
  • Mark questions for review to easily re-check them before submitting.
  • When the timer expires, your test will be submitted automatically.
  • Answers are evaluated and scored persistently on the secure server.
